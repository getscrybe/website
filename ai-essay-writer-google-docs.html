Frequently asked questions

Is there an AI essay writer built for Google Docs?

Yes — Scrybe is a Chrome extension that works inside Google Docs, generating an essay and typing it into the open document with simulated keystrokes.

How do I install it?

Install Scrybe from the Chrome Web Store, open a Google Doc, open the Scrybe sidebar, and sign in with Google.

Does Scrybe read my document?

It accesses the page only to find the editor and type into it. It does not read, copy, or store your document's existing contents.

Does it work on a Chromebook?

Yes. Because it's a Chrome extension, it runs anywhere Chrome does, including Chromebooks.
