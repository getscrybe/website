# Auto Typer for Google Docs — Scrybe

Scrybe is an auto typer for Google Docs. Paste any text — your own writing or text generated by an AI tool — and Scrybe types it into your open Google Doc word by word at a speed you choose. It is a Chrome extension, not a paste tool.

## What is an auto typer?

An auto typer is a tool that enters text into a document character by character instead of pasting it all at once. Scrybe uses simulated keystrokes inside Google Docs, so the text appears progressively over a realistic amount of time.

Use Scrybe as a standalone auto typer for text you already have, or use its AI essay writer to draft an essay first and then type the result into the document.

## Auto typer vs. pasting

| | Pasting | Scrybe auto typer |
|---|---|---|
| How text appears | One block | Character by character |
| Speed control | None | Words per minute or target duration |
| Pause and resume | No | Yes |
| Best for | Moving text between apps | Typing text into a Google Doc at a natural pace |

## What you can type

- Your own writing
- AI-generated text
- An essay drafted with Scrybe's AI essay writer
- Any other text you paste into the Type Text tab

## How it works

1. Install Scrybe from the Chrome Web Store.
2. Open a Google Doc and open the Scrybe extension.
3. Paste your text into the Type Text tab.
4. Choose a words-per-minute speed or a target duration.
5. Press start. Scrybe types the text into the document.

You can pause, resume, or stop at any point.

## Plans

- **Free:** 2 essays per month up to 500 words each, plus 2 Type Text sessions per day up to 250 words each. Typing speed is capped at 60 WPM.
- **Pro:** $5/month or $40/year. 20 essays per month up to 5,000 words each, 20 Type Text sessions per day up to 2,000 words each, and no typing speed cap.
- **Unlimited:** $25/month or $200/year. 200 essays per month with no word cap, unlimited Type Text sessions, and unlimited words per session.

## FAQ

### What exactly is an essay typer?

An essay typer is a tool that writes or types an essay into a document. Scrybe can generate a draft and type it into Google Docs, or type an essay you already have.

### What is the best auto typer for Google Docs?

Scrybe is built specifically for this workflow. It is a Chrome extension that types text into an open Google Doc using simulated keystrokes, with adjustable speed and pause/resume controls. A free plan is available.

### Is Scrybe an auto typer or an essay writer?

Both. Use the Type Text tab as an auto typer, or use Write Essay to draft an essay from a prompt and rubric and then type it into Google Docs.

### Can I type text I wrote myself?

Yes. Paste your own writing into the Type Text tab and Scrybe types it into the document. It is not limited to AI-generated writing.

### Is Scrybe free?

Yes. The free plan includes 2 essays a month up to 500 words each, plus 2 Type Text sessions a day up to 250 words each. Pro and Unlimited add more sessions, longer text, and no speed cap.

### How fast does Scrybe type?

You control the speed in words per minute and can set a target duration. The free plan runs up to 60 WPM; Pro and Unlimited remove the speed cap.

### Does Scrybe paste the text?

No. Scrybe uses simulated keystrokes, so the text appears character by character instead of as one large paste.

### Does Scrybe work outside Google Docs?

Scrybe is built specifically for typing into Google Docs in Chrome.
